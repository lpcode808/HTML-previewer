How the HTML Playground works

Get started in three steps

  1. Ask Gemini to make something, then copy the code it gives you.
  2. Paste it into the Your code box. Your creation appears on the right, ready to use.
  3. Change it: edit the code yourself, or ask Gemini for changes and paste the new version. When you are happy, click Download.

What to ask Gemini

Add this sentence to your request so Gemini gives you code that works here:

Make it a single HTML file with all of the CSS and JavaScript inside it. Don't use React or any build tools. Give me the complete file in one code block.

Want a change? Tell Gemini what to change and ask for the complete updated file. Then click Paste to replace your code with the new version.

Take your creation home

  1. Click Download. A file called my-creation.html goes to your Downloads folder.
  2. Double-click the file. It opens in your web browser and works without this website.
  3. To share it, send the file by email or put it in a shared drive. Other people should download it and open it in a browser. (Google Drive and some email apps show the code instead of running it.)

Your code is also kept in this browser on this computer, so it will still be here if you refresh the page. It will not be there on a different computer, in a private window, or after clearing browser data. Download it to keep it.

If something goes wrong

  • Blank preview? Make sure you copied all of the code. It usually starts with <!DOCTYPE html> and ends with </html>.
  • A problem message under the preview? Click Copy for Gemini, paste it into Gemini, and paste the fixed code back here.
  • Page frozen? Some code never stops running. Close the tab or reload the page. The playground will open paused so you can fix the code. You can also add ?safe to the end of the web address to open it paused.
  • Images or fonts missing? Those come from the internet. Check your connection.

About the preview

Your creation runs inside a locked-down box, called a sandbox. Inside it, buttons, sliders, animations, sound, drawing, and calculations all work. It cannot see or change this page, and it cannot read anything this playground saved on your computer.

Being honest about the limits:

  • Code in the preview can still use the internet: it can load images, fonts, and code from other websites, and it can send information to them. Only run code you got from a source you trust.
  • Code can still slow down or freeze your browser, for example with a loop that never ends.
  • Anything your creation saves while you preview it (like a high score) is forgotten each time the preview restarts. In the downloaded file, saving works normally.
  • Some browser features are blocked in the preview: camera, microphone, location, cookies, and opening links that need a sign-in. Pop-up windows and links in new tabs open with the same restrictions. These usually work in the downloaded file.
  • Links to other files on your computer (like picture.png) do not work, because the playground only has the one file you pasted.

This website has no accounts, no tracking, and no analytics. Your code never leaves your browser unless the code itself contacts the internet.
